# ctrlia-claude-code-otros-editores

The Spanish version is in the repository root and in [README.md](README.md); the English files are in `en/`.

A comparison table of how to use **Claude Code outside VS Code**: JetBrains (IntelliJ, PyCharm, Android Studio…), Visual Studio 2022/2026, Xcode 26.3, Zed, Cursor, Devin Desktop (formerly Windsurf) and Neovim. For each editor: who maintains the integration (Anthropic, the editor vendor or nobody), how to install it, which account pays for it and which Claude Code features you lose, with the official link next to it.

- The table: [en/TABLA.md](en/TABLA.md) (Español: [TABLA.md](TABLA.md))
- Page with the full explanation: https://ctrlia.dev/en/recetas/claude-code-otros-editores.html
- Español: https://ctrlia.dev/recetas/claude-code-otros-editores.html

Reviewed with Claude Code **2.1.316** on Nov 1, 2026. Official documentation only; we do not recommend third-party extensions.

## How to use it

Open `en/TABLA.md`, find your editor and follow the link in the "Source" column. If your editor is not listed, the official route is to install the CLI and run `claude` in its integrated terminal.
